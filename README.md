# Think Twice

[Open the prototype](https://think-twice-theta.vercel.app)

- **Routine payment:** Karen → Utilities → Pay $64.80.
- **Suspicious payment:** Karen → Messages → open the thread → open the link → Pay $12.75. Switch to Emily, open the alert, and approve or decline. Switch back to Karen to see the result.

The reset button clears the demo. Both roles share state in the same browser profile, including across tabs. Payments, risk analysis, and notifications are simulated. All names, phone numbers, and domains used in the scenario are fictional.

Run locally with `python3 -m http.server 8080 --directory public`.
